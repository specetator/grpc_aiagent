## 阶段一设计边界

新 Compose 项目为 `sparkpush`；原依赖配置保存在 `docker-compose.dev.yml`，
旧脚本显式选择开发文件，保持原卷身份。基础服务唯一宿主机入口为 9010。
内部 RPC 保持原角色校验与 TLS 门禁，首次初始化生成持久随机密钥和带服务
DNS SAN 的证书。数据库 root 凭据仅提供给初始化、MySQL 和迁移容器。

迁移入口先识别旧表，再创建当前基线；同一 MySQL 连接持有命名锁，迁移记录
文件 checksum，DDL 支持重入但不宣称事务回滚。缺可靠 allocator 的早期库先
停止旧写入、排空 Kafka 并备份；不会盲目反复重置 delivered 游标。

构建和实际运行证据、提交、镜像 digest、Release 链接将在对应阶段完成后登记。
在全部要求取得当前版本证据之前，目标保持进行中。
